**`src/dataset.py` explained, block by block**

*Paths block.* `REPO_ROOT = Path(__file__).resolve().parents[1]` — "the folder two levels above this file" — so the code finds `data/` no matter where you run it from, and no hard-coded `C:\uni\...` like your assignment had. `CIFAR10_MEAN/STD` are the published per-colour averages; not used yet, they're for the normalisation transform when we train.

*`_read_batch()`.* Opens one pickle. The raw data is a table of 10,000 rows × 3,072 numbers; the first 1,024 numbers of a row are the red channel, then green, then blue. `.reshape(-1, 3, 32, 32)` folds each row back into 3 colour sheets of 32×32, and `.transpose(0, 2, 3, 1)` reorders it to height-width-colour, which is what matplotlib and most image tools expect. *`load_cifar10()`.* Reads the 5 training batches, glues them into one 50,000-image array (`np.concatenate`), reads the test batch, and reads the class names from `batches.meta`. Returns one dictionary with everything. ~180 MB in RAM.

*`make_stratified_split()`.* This is the heart of the "split" question. For each of the 10 classes: find all its positions, shuffle them with a seeded random generator, take the first 500 for val and the rest for train. *`_write_split_csv` / `_read_split_csv` / `get_or_create_split()`.* Save the chosen indices as `data/splits/train_idx.csv` and `val_idx.csv` (columns: index, label, class_name).
